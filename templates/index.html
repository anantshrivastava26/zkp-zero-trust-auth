How the layered gate works

Access only unlocks when cryptographic proof and policy evaluation both pass.

  1. Registration: create key pair, store only public key.
  2. Challenge: compute Schnorr proof using private key client side.
  3. Verification: validate proof equation on server.
  4. Policy decision: evaluate time, source, reputation, risk score.
  5. Grant: redirect to dashboard only on full pass.
