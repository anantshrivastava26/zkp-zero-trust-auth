⚙ How it works

  1. Register – server generates a key-pair (G^x mod P). Only the public key is stored.
  2. Login – client sends username + private key → server runs the Schnorr proof locally.
  3. Verify – server checks G^s · y^c ≡ t (mod P) without ever knowing your secret.
  4. Policy gate – Zero Trust engine checks time-of-day, IP reputation and risk score.
  5. Access – only if BOTH ZKP and policy pass is the dashboard unlocked.
